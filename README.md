# Allp APT repository

Signed Stable packages for amd64 and arm64.

Installation: **https://allp-manager.github.io/apt/**

One-time repository setup is required; then use `sudo apt install allp`.
The initial v0.6.5 build requires glibc 2.39 (Ubuntu 24.04+ / Debian 13+).
